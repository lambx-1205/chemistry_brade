# CHEMISTRY BRADE

化学構造式をブレードの形のもとにして対戦する、ブラウザゲームのプロトタイプです。

## 現在の機能

- 分子名を入力して PubChem の化学構造データを検索
- 入力途中に、内蔵した学習用分子の候補を表示（クリックまたは矢印キー＋Enterで選択）
- よく使う日本語の一般名は、対応する英語名でも検索
- 分子式・IUPAC名・CID・SMILES を表示
- RDKit.js で SMILES から2D構造式を描画
- 候補が複数ある場合、表示する候補を選択
- モバイル画面にも対応

## 仕組み

- **PubChem PUG REST**: 分子名からCIDを探し、構造情報を取得します。
- **RDKit.js**: 取得したSMILESを読み取り、2D構造式をSVGで描画します。
- **入力中の候補表示**: ネットワークへ毎キー入力を送らないよう、学習用分子の小さな辞書から即時候補を出します。候補辞書はPubChem全体を網羅するものではありません。候補にない分子名も、入力欄からそのまま検索できます。
- APIと描画ライブラリはインターネット経由で読み込むため、動作には接続が必要です。GitHub Pages側にサーバーやビルド工程を追加する必要はありません。

## これからの実装

3Dモデルは分子の原子座標を立体表示するものではなく、**2D構造式に厚みをつけ、コマのブレードとして扱う**方針です。そのため、次の段階では2D構造式の線や輪郭を立体形状に変換する方法を検討します。

1. 分子名から構造式を取得する（現在）
2. 2D構造式の輪郭に厚みをつけてブレード化する
3. コマとアリーナの物理演算を実装する
4. 分子構造とブレードの形状・性能を結びつける
