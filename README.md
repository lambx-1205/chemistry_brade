# CHEMISTRY BRADE

化学構造式をブレードの形のもとにして対戦する、ブラウザゲームのプロトタイプです。

## 現在の機能

- 分子名を PubChem の化学構造データから検索
- **PubChem の公式オートコンプリートAPI**を接続し、入力途中から実在する化合物名の候補を取得
- ネットワーク候補が使えない場合も、日本語別名辞書の候補は表示
- 完全一致検索に失敗した場合も、オンライン候補を提示して別表記を選べる
- 分子式・IUPAC名・CID・SMILES を表示
- RDKit.js で SMILES から2D構造式を描画
- 分子式から原子数を数え、分子の大きさに応じて結合線幅・二重結合の間隔・余白・ラベルサイズを自動調整
- Three.js を使い、SVG内の色付きパスと線幅を持つストローク部分だけを押し出した3Dプレビューを生成（背景・空白領域は立体化しない。ドラッグで回転、スクロールで拡大・縮小）
- 候補が複数ある場合、表示する候補を選択
- キーボード操作とモバイル画面に対応

## 仕組み

- **PubChem Auto-Complete Search Service**: 入力が少し止まったタイミングで、化合物名の候補をオンライン検索します。キー入力のたびに即時通信するのを避けるため、約0.3秒の待ち時間を設けています。
- **PubChem PUG REST**: 候補を選択したら化合物CIDと構造情報を取得します。
- **RDKit.js**: 取得したSMILESを読み取り、2D構造式をSVGで描画します。
- APIと描画ライブラリはインターネット経由で読み込むため、動作には接続が必要です。GitHub Pages側にサーバーやビルド工程を追加する必要はありません。

オンライン候補は手作業で登録した名前だけに限定されません。ただし、PubChemに存在しない化合物や、データベースに認識されていない表記は特定できない場合があります。特に日本語名が候補に出ない場合は、英語名やIUPAC名など別の表記を使ってください。候補が表示されても、それが意図した異性体かは名前と分子式を確認してください。


3Dプレビューは、SVG内で色が付いているパス形状と、線幅を持つストローク部分だけを奥行き方向に押し出す試作です。背景・白色・透明な領域はメッシュを生成せず、SVGの塗り色を引き継ぎます。3DモデルではSVGの線幅を1.5倍（最低幅1.8）にして、細い線が目立たなくなるのを抑えます。厚みはSVG全体の最大寸法の4.5%に設定し、モデルの前後方向の中央に配置します。原子ラベルが塗りつぶしパスとして出力される場合は、その文字形状も押し出されます。衝突判定・物理演算は未実装です。

## これからの実装

3Dモデルは分子の原子座標を立体表示するものではなく、**2D構造式に厚みをつけ、コマのブレードとして扱う**方針です。そのため、次の段階では2D構造式の線や輪郭を立体形状に変換する方法を検討します。

1. 分子名から構造式を取得する（現在）
2. 押し出した色付きパスをブレード形状として調整する
3. コマとアリーナの物理演算を実装する
4. 分子構造とブレードの形状・性能を結びつける

## GitHub Pages

`.github/workflows/pages.yml` は `main` への push 時に静的サイトをデプロイします。初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選んでください。デプロイの成否は **Actions** タブで確認できます。
